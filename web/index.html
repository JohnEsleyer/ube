🍠 Ube Language

The sweet, grounded systems language. Fast like C, easy like Go, Zero GC.

Quickstart

# Clone and test Ube
git clone https://github.com/JohnEsleyer/ube.git
cd ube
make test

# Build and run
./bin/ube run examples/01_hello/main.ube
🚀 Fast as C / Rust

Contiguous layouts, monotone bump growth on Tubers, single-store deallocation, and no garbage collection pauses.

🧁 Easy as Go

Minimalist syntax, Go-style receiver methods, channels, and fast compilation without lifetime annotations.

⚡ Zero-Cost C Interop

Direct bindings via extern fn, drop-in single-file C support, and clean ANSI C99 output.
