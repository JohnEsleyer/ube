🍠 Ube Language

The sweet, grounded language for games, apps, and backends. Fast like C, clean like Go, Zero GC, 100% Wasm-Native.

Quickstart

# Clone and build the Go compiler
git clone https://github.com/JohnEsleyer/ube.git
cd ube
go build -o bin/ube ./cmd/ube

# Build a sandboxed Wasm module (main.wasm)
./bin/ube build examples/01_hello/main.ube

# Run it with any Wasm runtime
./bin/ube run examples/01_hello/main.ube

# Or produce a browser-ready Web Canvas app
./bin/ube build examples/01_hello/main.ube --html -o hello.html
🎮 High-Level & Pragmatic

Engineered for game loops, UI applications, and cloud backends without low-level systems complexity or raw pointer baggage.

🧁 Clean Like Go

Readable syntax, Go-style receiver methods, channels, and shared-nothing concurrency without data races.

🛡️ Safety Without Lifetime Tax

Zero GC pauses and deterministic reclamation using lexical bump arenas and generational entity pools without Rust-style lifetime annotations.

🌐 100% Wasm-First

Naturally sandboxed, ultra-fast sub-millisecond cold starts, and identical execution across browser, desktop, and cloud servers.

Language status and roadmap

The compiler frontend is written in Go and is Wasm-first: ube build emits portable .wasm modules, while --html produces a Web Canvas/UI app. The runtime uses pure Wasm linear memory, cooperative task scheduling, and typed host imports instead of POSIX threads or OS headers. Language features include arena-backed dynamic slices with geometric growth, generational pools, polymorphic printing, short-circuiting && and ||, and loop break/continue.

Planned work: richer browser/GPU host bindings, WASI networking profiles, and deeper cooperative scheduler integration. The compiler will remain in Go; a self-hosting Ube compiler is not planned.
