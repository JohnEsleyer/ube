🍠 Ube Language

The sweet, grounded systems language. Fast like C, easy like Go, Zero GC.

Quickstart

# Clone and build the Go compiler
git clone https://github.com/JohnEsleyer/ube.git
cd ube
go build -o bin/ubec ./cmd/ubec

# Generate C, compile, and run
./bin/ubec examples/01_hello/main.ube -o output.c
gcc -std=gnu11 -O2 -pthread -Iruntime output.c -o ube_app
./ube_app
🚀 Fast as C / Rust

Contiguous arena-backed slices with geometric growth, scope-based reclamation, and no garbage collection pauses.

🧁 Easy as Go

Minimalist syntax, Go-style receiver methods, channels, and fast compilation without lifetime annotations.

⚡ Zero-Cost C Interop

Direct bindings via extern fn, drop-in single-file C support, and clean C output.

Language status and roadmap

The compiler frontend is written in Go and emits C. Current language features include arena-backed dynamic slices with geometric growth, polymorphic printing, short-circuiting && and ||, and loop break/continue.

Planned work: cooperative M:N fiber scheduling, then WebAssembly and embedded target profiles. The compiler will remain in Go; a self-hosting Ube compiler is not planned.
